# 萤火虫 · 位图转真矢量（SVG / PDF）

桌面小工具：把 PNG / JPG / WebP / BMP / TIFF 转成**真正的矢量** SVG 和 PDF（路径，不是把图片塞进文件里）。

给自用和朋友用，免费。没有安装器，解压即用。

**详细说明见 [`使用说明.md`](使用说明.md)，或程序里右上角的「使用说明」按钮**（内容一致）。
下面是简介。

---

## 先看清楚：什么样的图能"准确"转

| 图片类型 | 效果 | 说明 |
|---|---|---|
| 黑白线稿、logo、技术图纸、印章 | **很好（A 级）** | 实测 SSIM 0.993–0.996，体积 0.05–0.8 倍 |
| 扁平图标、纯色插画 | **好（A 级）** | 实测 SSIM 0.996，体积约 0.05 倍 |
| 图表截图 | 一般（B 级） | 实测 SSIM 0.96，能看清但个别文字/细线会走样 |
| 文字截图 | 一般（B 级） | 实测 SSIM 0.97，字变成**轮廓**，不能选中、不能搜索、不能改字 |
| 像素画 / 马赛克 | 形状准（A 级）但**文件会变大** | 每个色块都要单独路径，可达原图 10 倍 |
| 渐变 / 阴影 / 发光 | 会出色带（C 级） | 平滑渐变会被切成若干色块 |
| 照片 | **做不到准确** | 只能得到"矢量化的画"，或把原图嵌进去（那就不是真矢量的意义了） |

工具每次转换完会做一次**质量自检**（把输出栅格化回来和原图比 SSIM + 平坦区误差），给 A/B/C 分级。
看到 C 就别指望它比原图好看。

## 运行

需要 Python 3.10+。

```powershell
pip install -r requirements.txt
python run.py
```

`potrace.exe` 已经放在 `bin/potrace/`，不用另外装。

命令行批处理（不给别人用 GUI 时很方便）：

```powershell
python -m firefly.cli 图片1.png 图片2.jpg -o 输出目录
```

## 用法

1. **添加图片**（可多选、可批量）。
2. 选输出目录。
3. 点**开始转换**。每个文件同时产出 `.svg` 和 `.pdf`（同名旧输出会被覆盖）。
4. 看结果表的 **等级**：
   - **A**（SSIM ≥ 0.98 且平坦区误差 < 1.5）：可以直接用。
   - **B**（SSIM ≥ 0.92）：能用，细看边角。
   - **C**：这张图不适合矢量化，换思路（见上表）。
5. 双击某一行，直接用系统默认程序打开生成的 SVG。

### 设置项

- **路线**：默认「自动」。黑白/低色彩图自动走 potrace 单色描迹；彩色走 vtracer。
- **二值化**：默认 Otsu（全局阈值）。扫描件、光照不均的照片走 **Sauvola**，窗口 51 左右起步，图越大窗口越大。
  选了 Otsu 时「Sauvola 窗口」会自动置灰（这个参数对 Otsu 无效）。
- **线条类细节**：平滑优先 / 标准 / 细节优先——影响 potrace 的拐点平滑度与杂点阈值。技术图纸用「细节优先」，手绘线条用「平滑优先」。
- **彩色类风格**：
  - **平涂图标**（默认，polygon + 较强碎块过滤）：纯色块图标、界面元素，体积最小。
  - **标准**（polygon）：颜色分层更细一些，彩色插画、图表用这个。
  - **细节优先**（spline）：保留最多细节，文件可能比原图大好几倍。
- **反色**：白线黑底的图（比如暗色主题截图）勾上。
- **恢复默认设置**：设置卡底部，点一下就回到上面所有默认值。

## 界面

浅绿配色（`#F2F7F2` 底 + 白卡），主色深绿 `#1F8A6E`。标题栏左侧是「萤火虫」字标。
结果表按等级整行着色：A 淡绿 / B 淡橙 / C 淡红。

配色和控件尺寸都集中在 `firefly/gui.py` 顶部的 `C_*` 常量里，改一处即全局生效。

---

## 输出是"真矢量"吗

是。PDF 里没有一张内嵌位图，全部是路径填充算子；SVG 里全是 `<path>`。

架构上**不是** `PNG → SVG → PDF` 串联，而是两个格式都从同一份几何路径集（IR）直接发射，
所以 SVG 和 PDF 内容一致，PDF 不会因为再解释一次 SVG 而掉精度。

## 打包成 exe 给朋友

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物在 `dist\firefly\`。整个文件夹压缩发出去即可（不要只发单个 exe，
里面的 `bin\potrace\potrace.exe` 必须一起带上）。

朋友那边解压后双击 `firefly.exe` 就能用，不需要装 Python。
exe 自带图标（任务栏和资源管理器里显示为发光的萤火虫光点）。
